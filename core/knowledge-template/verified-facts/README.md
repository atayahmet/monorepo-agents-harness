# Verified Facts

One `[task_slug].md` page per task whose `4_verify.md` proved something verifiable — what was
proven, how (command/evidence), and by which task. Compiled by the ingest workflow
(`core/scripts/kb-ingest.sh`). A fact without a `Sources:` footer linking its `4_verify.md` must not
ship. See `../schema.md` for naming and citation rules.
